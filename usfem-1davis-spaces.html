Reserve a 1 Davis space

You can book up to a year in advance. Booking requires a USF sign-in.

How to book

Four steps in Microsoft Bookings.

  1. Select a servicePick the room and length, such as “Classroom – 4 hours”. Use “Show more services” to see them all.
  2. Select staffChoose the room listed, or leave it on “Anyone”.
  3. Select a date and start timeTimes are shown in Eastern Time.
  4. Enter contact info and bookYou’ll get a confirmation for your reservation.

Space rules

Shared space works when everyone leaves it as they found it.

  • Return furniture

    If you move furniture, return it to the space where you found it.

  • Cancel if needed

    If you no longer need the space, cancel online so others can use it.

  • Leave it ready

    Tidy up after yourself and your group, and leave the space ready for others.

See a space open while you’re in the office? Book it on the calendar so others know it’s occupied.
